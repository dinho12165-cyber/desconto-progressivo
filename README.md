     # Desconto-Progressivo
Este programa foi implementado para um estabelelcimento para oferecer descontos progressivos aos cliente,ele é aplicado de acordo com o valor da compra,
inicia com desconto 5% de  para compras abaixo de 200 reais,
prossegue com desconto 10% para compras entre 200  e 300 reais,
e por ultimo desconto de 15% para compras acima de 300 reais.
